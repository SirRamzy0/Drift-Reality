# Drift Reality

Аркадная гоночная игра с процедурной генерацией трасс, турнирной системой и продвинутым AI. Проект разрабатывается на Unity 6 с ориентацией на платформы **WebGL** (Яндекс.Игры) и **Windows**.

## Особенности

- **Процедурная генерация трасс** — каждый раунд генерируется уникальная дорога с прямыми участками, поворотами и шпильками по сплайнам Catmull-Rom.
- **Турнирная система** — 50 участников, 3 раунда с отсевом (25 → 10 → финал).
- **Три класса AI-пилотов**:
  - *Leader* — агрессивные и быстрые лидеры.
  - *Pack* — сбалансированные гонщики середины пелотона.
  - *Wildcard* — непредсказуемые соперники, склонные к ошибкам.
- **Кастомная аркадная физика** — полностью ручное управление скоростью, сцеплением, дрифтом и нитро без использования WheelCollider.
- **Дрифт и нитро** — механика заряда дрифта с импульсом при выходе, кулдаун нитро.
- **Отбойники и прыжки** — взаимодействие с ограждениями и возможность подпрыгивать.

## Управление

| Клавиша | Действие |
|---|---|
| `W` / `S` | Газ / тормоз |
| `A` / `D` | Поворот |
| `Space` | Прыжок |
| `Shift` / `ПКМ` | Дрифт |
| `ЛКМ` | Нитро |

## Архитектура

### Основные скрипты (`Assets/scripts/`)

| Скрипт | Назначение |
|---|---|
| `RaceBootstrap.cs` | Центральный менеджер гонки: турнир, раунды, спавн участников, HUD, экраны результатов. |
| `ProceduralRoadGenerator.cs` | Генератор дороги из контрольных точек через Catmull-Rom сплайны с мешем и обочинами. |
| `ArcadeCarController.cs` | Полностью кастомная физика машины: движение, поворот, дрифт, нитро, прыжки, респавн. |
| `AiCarController.cs` | AI-пилот с оценкой поворотов, выбором полосы, ошибками и использованием нитро/дрифта. |
| `CarHandlingProfile.cs` | ScriptableObject-профиль управляемости (~30 параметров) с вариациями для соперников. |
| `FollowCamera.cs` | Плавная камера следования с динамическим FOV. |
| `FinishLineTrigger.cs` | Триггер финишной линии. |
| `MainMenuController.cs` | Программно построенное главное меню. |
| `RoadGuardrailBuilder.cs` / `RoadGuardrailCollision.cs` | Генерация и обработка столкновений с отбойниками. |
| `VehicleVisualEffects.cs` | Визуальные эффекты машины (поворот колёс, деформация). |
